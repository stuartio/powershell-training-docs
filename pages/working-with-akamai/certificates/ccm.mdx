# Cloud Certificate Manager

Cloud Certificate Manager is the planned replacement for CPS, and is currently in the beta phase. Its functionality is limited compared to its predecessor, but the currently available API endpoints are supported in PowerShell.

## Installation

The CCM sub-module is not publicly available, due to the beta status. To install it you must access the Download Center inside Akamai Control Center, from an account which has CCM included in one of its contracts.

The direct link is here - https://control.akamai.com/apps/download-center/#/products/24;name=Scope-of-Integrations . Expand the PowerShell Submodules section and you should see all the submodules to which your account is entitled.

## Usage

The CCM sub-module, at present, only supports third-party certificates, and its 7 functions are largely centered around CRUD operations for certificates.

| Function | Description |
| --- | --- |
| Get-CCMCertificate | List all CCM certificatess, or retrieve a specific certificate by its ID. |
| New-CCMCertificate | Create a certificate. |
| Remove-CCMCertificate | Delete a certificate. |
| Rename-CCMCertificate | Rename a certificate. |
| Set-CCMCertificate | Update a certificate. |
| Add-CCMSignedCertificate | Add a signed certificate to an existing certificate. |
| Get-CCMBinding | List a certificate's hostname bindings. |

```powershell
$CreationBody = '{
    "certificateName": "My Certificate",
    "subject": {
        "commonName":   "www.example.com",
        "country":      "US",
        "locality":     "Oceanside",
        "organization": "Akamai Technologies",
        "state":        "CA"
    },
    "keySize":         "2048",
    "keyType":         "RSA",
    "sans":            [
        "www.example.com",
        "example.com"
    ],
    "secureNetwork":   "ENHANCED_TLS"
}'
$Cert = New-CCMCertificate -Body $CreationBody
```

> It is always a good idea to assign the result of any command to a variable, so you can reuse the data later. As you can see above, quite a lot of info is returned when creating a certificate, including the CSR PEM, which you will need to submit to your CA.

## Updating certs

Once your certificate object is created, you must have it signed by a third party CA. This is beyond the scope of what we are talking about here, but for testing purposes you can search online for openssl commands you can use to create a self-signed certificate from the CSR PEM. Once you have your signed certificate, you can add it to the existing certificate object using `Add-CCMSignedCertificate`.

First, let's say you have retrieved your certificate as a PEM-encoded text file named `cert.pem`, and your trust chain in the same format in a file called `chain.pem`. You can use the following commands to read them into variables, and then add them to your certificate object.

## Working with existing certs

You can retrieve your certificate with `Get-CCMCertificate`, though it does not currently supported retrieving individual certificates by name (this is planned for a later release). Typically, if you do not know your certificate ID, you would retrieve all certs and filter by name.

```powershell
$Certs = Get-CCMCertificate
$Cert = $Certs | Where-Object { $_.certificateName -eq 'My Certificate' }
```

Then you can edit various elements of the certificate object, and use `Set-CCMCertificate` to update it. For example, if you wanted to change the name of your certificate:

```powershell
$Cert.certificateName = 'My New Certificate Name'
$Cert | Set-CCMCertificate
```

> You can also use this method to upload the signed certificate and trust chain, as an alternative to `Add-CCMSignedCertificate`.

Alternatively, you can use `Rename-CCMCertificate` to change the name of a certificate.

```powershell
$Cert | Rename-CCMCertificate -CertificateName 'My New Certificate Name'
```

Finally, you can remove your certificate with `Remove-CCMCertificate`.

```powershell
$Cert | Remove-CCMCertificate
```

## Discovering Cert Bindings

The CCM also allows you to discover which hostnames are bound to which certificate. You can list the bindings globally, or with a single certificate ID, like this:

```powershell
Get-CCMBinding | Where-Object hostname -eq 'www.example.com'

active        : True
certificateId : 1234
hostname      : www.example.com
network       : STAGING
resourceType  : CDN_HOSTNAME
```

Or

```powershell
$Cert | Get-CCMBinding

active        : True
certificateId : 1234
hostname      : www.example.com
network       : STAGING
resourceType  : CDN_HOSTNAME
```
