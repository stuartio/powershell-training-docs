# Certificates

Certificate automation is a common topic when working with Akamai, both in the creation and update areas, but also with auditing. Akamai provides several APIs to work with certificates, all of which are supported in PowerShell.

| API | Purpose | PowerShell module | Guide |
| --- | --- | --- | --- |
| Certificate Provisioning API (CPS) | Create, update, and manage Edge Certificates (original) | Akamai.CPS | (Guide)[../working-with-akamai/cps.mdx] |
| Cloud Certificate Manager API (CCM) | Create, update, and manage Edge Certificates (updated) | Akamai.CCM | |
| Default DV | Work with simplified Default DV certificates | Akamai.Property | |
| mTLS Edge Truststore API (METS) | Configure Client to Edge mTLS CA Certificates and settings | Akamai.METS | |
| mTLS Origin Keystore API (MOKS) | Configure Akamai to Origin mTLS certificates and settings | Akamai.MOKS | |
