# Client & Network Lists

Often, security changes on the Akamai platform can be as simple as adding or removing elements from a list. This is used to block bad actors, beligerant nations, or to allow users to test non-production systems. Akamai provides two mechanisms for managing lists: Network Lists and Client Lists.

| Product | SubModule | Description | Guide |
| --- | --- | --- | --- |
| Network Lists | Akamai.NetworkLists | The legacy system for working with lists, supporting only IP and GEO lists. | [Guide](./lists/network-lists.mdx) |
| Client Lists | Akamai.ClientLists | The newer system for working with lists, with many more list types. | [Guide](./lists/client-lists.mdx) |
