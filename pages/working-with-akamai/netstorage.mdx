# Netstorage

Netstorage is a commonly used storage platform for most Akamai customers, despite the increasing popularity of Akamai Cloud's Object Store feature. Working with Netstorage in PowerShell involves interacting with two separate APIs; the configuration API, which is used to create and manage storage groups, upload accounts etc., and the usage API, which is used to perform file operations directly, such as uploading, downloading and the like.

Both APIs are covered by the Akamai.Netstorage module, though there are fundamental differences between the two that you should understand. Check the below guides for more information on each of the modules:

- [Configuring Netstorage](./netstorage/configuration.mdx)
- [Managing Files](./netstorage/files.mdx)
